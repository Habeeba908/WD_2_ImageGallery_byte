# VisualVault — AVIP Web Development Task 2 (Advanced)

Responsive React image library with collections, uploads, search, favorites and full-screen lightbox.

## Run
Requires Node.js 18+ and npm.
```bash
npm install
npm run dev
```
Create a production build with `npm run build`.

## Task 2 requirements covered
- Responsive image grid.
- Enlarged lightbox with previous/next and close controls.
- Captions and meaningful alt text.
- Six local sample illustrations in `public/sample-images/` (work offline).
- Upload images, create/delete collections, move assets between collections, rename assets, search and favorite.

## Storage note
Asset metadata and uploaded image data are stored in browser `localStorage`, not a cloud database. Browser storage is limited; use smaller images. Clearing site data removes local changes.
